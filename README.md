##Decay — Legacy Edition

A dark fantasy RPG originally built as a passion project to deepen my understanding of C++ and game development.

Originally starting as a simple console application, Decay evolved into a fully windowed SFML-based project featuring:

dialogue systems
branching encounters
combat mechanics
exploration systems
custom animations
save/load functionality
multiple areas, enemies, and story events

This repository contains the original completed legacy release of the project before later architectural rewrites and engine restructuring.

About This Version

This version represents the original large-scale implementation of the game and was developed primarily as a learning experience while exploring:

object-oriented programming
game state management
UI systems
combat logic
animation systems
event scripting
asset handling

The codebase is intentionally preserved largely as-is to document progression and growth over time.

Because of that, the project contains:

legacy design patterns
experimental systems
rough architecture in some areas
known bugs and inconsistencies

Despite that, the game is fully playable and serves as an important milestone in my progression as a developer.

###Features
Multiple explorable regions
Dialogue-driven encounters
Turn-based combat
Party members and leveling
Enemy variety and bosses
Animated combat effects
Save / Load system
Music and ambience
SFML-based rendering and audio
Known Issues
Some UI elements may occasionally fail to refresh correctly after loading saves
Certain combat/event systems rely on older state-management logic
Some systems were developed rapidly during experimentation and may behave inconsistently

This repository is preserved primarily for archival and historical purposes.

###Legacy Note

A significantly more advanced rewrite/refactor of the project exists separately from this repository. This version remains preserved as the original foundation the later work evolved from.
